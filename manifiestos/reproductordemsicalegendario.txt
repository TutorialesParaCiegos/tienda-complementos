--[[1.3
Cambio de nombre: Se ha renombrado oficialmente a "Reproductor de música legendario" para unificar y otorgar un nombre más formal.
Actualizaciones automáticas: A partir de esta versión, el complemento cuenta con un sistema de actualización integrado que te avisará de nuevas versiones o regresiones automáticamente.
Recepción de futuras versiones: Mientras tengas este complemento instalado, recibirás todas las nuevas actualizaciones y notificaciones de cambios directamente a través de él.
Soporte para regresiones: Si una actualización futura llega a tener errores, el sistema te avisará para regresar automáticamente a esta versión estable.
Ocultar contenido: Se añadió la opción de ocultar pistas individuales o carpetas completas manteniendo pulsada una canción. Puedes gestionarlas y restaurarlas fácilmente desde las configuraciones.
Mejoras de accesibilidad: Se optimizó el enfoque automático al abrir la interfaz y la búsqueda inteligente, que ahora reaplica el filtro automáticamente si ocultas o eliminas una canción mientras buscabas.
]]
